# v1.4.33 — sidebar labels, Muse Spark Open host wording, Zenodo recovery

2026-10-19. No analysis or score changes. The last items from Mira's weekly
release review (souls.house, message `jrnZlj`); v1.4.32 fixed Gemini prices.

- **Model-page sidebar.** The row labelled "Provider" showed the host of the
  cheapest OpenRouter listing at the last fetch. Beside a pinned first-party price
  it read as if that host were the price or capture source. DeepSeek V4.1 Flash
  1017, for example, showed DeepInfra next to DeepSeek's price, although every
  sample was captured through DeepSeek. The row is now labelled "Cheapest OpenRouter
  host" and says it is neither the price source nor the capture host. The price
  source keeps its own row, and the capture host is in each model's notes where
  one is recorded.

  time. The endpoint snapshot saved with the capture lists five hosts (Modal,
  Together, Nebius fp4, Fireworks, BaseTen fp4), none of them Meta. The notes now
  say what holds: no Meta endpoint, and every call pinned to Modal with no
  fallbacks. The site's model note already said only that.
- **Zenodo.** v1.4.27 (Muse Wonder) was never archived on 2026-10-13. Its GitHub
  release was re-published on 2026-10-19 and is now
  [10.5281/zenodo.23469036](https://doi.org/10.5281/zenodo.23469036), with a
  Zenodo date of 2026-10-19. Raw v1.2.33 likewise:
